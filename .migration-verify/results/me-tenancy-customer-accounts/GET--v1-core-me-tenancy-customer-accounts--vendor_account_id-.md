## DB Query Comparison

Dashboard Prisma query filters:
1. `account.onboarding_status_code IN ('active', 'unclaimed')`
2. `account_user.user_id = identity.actor.id AND account_user.status_code = 'active'`
3. `account_relation.owner_account_id = vendorAccountId AND account_relation.account_relation_role_code = 'customer'`
4. Returns: `id`, `name`

Go SQL query (after fix):
```sql
SELECT a.id, a.name
FROM account a
INNER JOIN account_user au ON au.account_id = a.id
INNER JOIN account_relation ar ON ar.counterparty_account_id = a.id
WHERE a.onboarding_status_code IN ('active', 'unclaimed')
  AND au.user_id = ?
  AND au.status_code = 'active'
  AND ar.owner_account_id = ?
  AND ar.account_relation_role_code = 'customer';
```

All filters match the Dashboard logic exactly.
